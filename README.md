# BSE/NSE-Stock-Forecaster
Our 6-member team recently built an AI-powered stock market forecasting and financial research platform for Indian equities. The system combines ensemble machine learning, technical analysis, financial sentiment analysis, and a Retrieval-Augmented Generation (RAG) pipeline to generate explainable BUY/SELL/HOLD signals and context-aware financial insights.

## Features
- NSE/BSE stock analysis using real-time market data
- ARIMA, SARIMA, Prophet, and XGBoost ensemble forecasting
- Technical indicators including RSI, MACD, Bollinger Bands, ATR, and Stochastic Oscillator
- FinBERT + TextBlob financial sentiment analysis
- RAG-based financial chatbot using FAISS and Sentence Transformers
- Annual report and financial document semantic search
- Risk metrics including Sharpe Ratio, Annualised Volatility, and Maximum Drawdown
- Interactive dashboard built with Streamlit
- Context-grounded financial Q&A using Groq LLaMA 3.1

## RAG Pipeline
The project integrates a Retrieval-Augmented Generation (RAG) architecture using:
- FAISS vector similarity search
- all-MiniLM-L6-v2 embeddings
- Sentence Transformers
- Groq LLaMA-3.1-8B-Instant API
- Semantic retrieval over financial reports and news data

The chatbot retrieves relevant financial context before generating responses, reducing hallucinations and improving financial reasoning quality.
